# dsh-whale-float · 小鲸鱼浮窗（手机版）

> 手机上的专属小鱼：DSH Web GUI 角落一个球，点一下平滑展开成卡片 —— 余额/峰谷时段 + 实时花销气泡。

| 能力 | 说明 |
|---|---|
| 余额 / 时段 | 来自本机 `pet-server`（127.0.0.1:8902）：余额、峰/谷时段与倒计时 |
| 实时花销 | 每步冒气泡：**输入一颗、输出一颗**（间隔 520ms 连发）；**命中=绿 / 未命中=红**；小字在数字左边；手写体（默认 6 Caveat + 中文马善政，可换 17 款） |
| 位置 | 球待在你放的地方不动；卡片按 `data-side/data-v` 朝放得下的那边展开；拖动记位置；开合从贴着球的角放大/缩回 |
| 交互 | 点球展开 · 「–」收起 · 「⟳」刷新 · 「字」换字体 · 长按收起/展开 |
| 自带后端 | `server/pet/`（原始 pet-server + 立绘）· `server/用量服务.mjs`（8903，零 token）· `server/字体/` |

## 装

```sh
node install.mjs --dry      # 先看要动哪些（幂等、只装本版本）
node install.mjs            # 真装
```

装完**重启引擎 + 刷新页面**。
